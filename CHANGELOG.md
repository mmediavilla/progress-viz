# Changelog

All notable changes to progress-viz. Versions follow [Semantic Versioning](https://semver.org).

## [0.2.0] - 2026-10-26

### Changed

- Agents are drawn as Blok, an original blocky pixel character, in place of Clawd. His shirt takes the role colour, and each role has its own hat and held prop: a pickaxe for Explorer, a shield for Security, a potion for QA, a clipboard for Reviewer, a map for Planner, a pencil for Drafter, a book for Guide, a wrench for Setup.
- The default role is now "Agent" and carries a flickering torch.
- The terminal avatar is redrawn to match.

## [0.1.3] - 2026-10-26

### Added

- First standalone release: an animated progress band above the prompt for the running turn, and an Agents pane with per-agent progress.
